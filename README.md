# 📄 ResumeCraft

**ResumeCraft** — это cli-генератор профессиональных резюме, который форматирует вводные данные в красиво оформленные документы в форматах **HTML**, **PDF** и **DOCX** из **JSON** и **YAML** файлов.  

---

## 🎨 Доступные темы

- **accent** - яркая тема с цветной шапкой на всю ширину и акцентными плашками для дат.
- **aurora** - двухколоночная тема с диагональным градиентным сайдбаром (акцентный цвет → тёмный) и карточками для опыта/образования/проектов.
- **black-green** - тёмная тема в стиле терминала.
- **clarity** - одноколоночная, современная, максимально читаемая тема. Акцентный цвет используется точечно: в подзаголовке, тонкой линии-разделителе и заголовках секций. Безопасна для ATS-парсеров.
- **classic** - одноколоночная тема в спокойных тонах с двойной рамкой.
- **compact** - максимально плотная тема почти без оформления, для длинного опыта на одной странице.
- **editorial** - традиционная, центрированная тема для консервативных сфер.
- **executive** - строгая деловая двухколоночная тема с крупными заголовками и светлым сайдбаром для контактов и навыков.
- **ivory** - тёплая премиальная одноколоночная тема на кремовом фоне, с малыми капителями в заголовках секций и тонким акцентным орнаментом.
- **cobblestone** - тёмная монохромно-графитовая тема в духе Palantir/Anduril/ICEYE/Gazprom: заголовки секций в квадратных скобках как в HUD, даты в моноширинной рамке, едва заметная блочная сетка на фоне, без скруглений и теней.
- **midnight** - тёмная тема для digital-резюме. Тёплый светло-серый цвет.
- **minimal** - простая одноколоночная тема без лишнего декора.
- **modern** - двухколоночная тема с цветным сайдбаром слева и акцентными плашками для навыков.
- **obsidian** - строгая институциональная тёмная тен.
- **slate** - двухколоночная корпоративная тема со светло-серым сайдбаром для контактов/навыков.
- **terminal** -Тема вдохновлённая теминаломи.

## ❓ Как пользоваться?

### Консоль

- `resumecraft [OPTIONS] [INPUT_FILE_NAME]`

### Опции [OPTIONS]

- `--help` - Список доступных команд.
- `--version` - Версия.
- `-o, --output PATH` - Директория вывода.
- `-f, --format [html|pdf|docx|all] [default: all]` - Выбор формата выходного документа. 
- `-t, --theme [clarity|midnight|obsidian|accent|editorial|slate|compact|terminal|modern|classic|minimal|executive|black-green|aurora|ivory|cobblestone] [default: clarity]` - Выбор темы.
- `-l, --lang [ru|en] [default: ru]` - Выбор языка.
- `--accent-color TEXT` - Цвет акцента в hex формате.
- `--font TEXT` - Шрифт.
- `--pdf-backend [chromium|weasyprint|pdfkit] [default: chromium]` - backend PDF генерации.
- `--wkhtmltopdf-path PATH` - Путь к wkhtmltopdf (использовать только с --pdf-backend pdfkit)
- `--config PATH` - Путь к resumecraft.toml.
- `--debug` - Включить debug логирование.
- `--list-themes` - Список доступных тем.

## ⬇️ Установка

Вы должны находиться в каталоге.

### Создайте и активируйте виртуальное окружение (рекомендуется)

**Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS/Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### Установите пакет со всеми зависимостями 

```
pip install -e .
```

или

```
pip install .
```

### Установите браузер для генерации PDF (опционально)

- **`chromium`** *(по умолчанию, рекомендуется)*
  
  **Windows (PowerShell):**
  
  ```
  pip install playwright
  playwright install --with-deps chromium
  ```

  **MacOS/Linux:**

  ```
  playwright install --with-deps chromium
  ```

- `weasyprin`.
- `pdfkit` + установленный [wkhtmltopdf](https://wkhtmltopdf.org/downloads.html *проект архивирован разработчиками в 2023 году)*
