# 📄 ResumeCraft

**ResumeCraft** — это генератор профессиональных резюме, который форматирует в ваши вводные данные в красиво оформленные документы в форматах **HTML**, **PDF** и **DOCX**.  

---

## 📦 Требования

- **Python 3.10** или новее.
- Для генерации **PDF** дополнительно требуется один из бэкендов:
  - `weasyprint` (рекомендуется, чисто Python, устанавливается через pip)
  - `pdfkit` + установленный [wkhtmltopdf](https://wkhtmltopdf.org/downloads.html)
